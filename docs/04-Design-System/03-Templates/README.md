# Overview

Templates define complete page blueprints constructed from approved components and established interaction patterns.

Unlike Components and Patterns, Templates describe fully assembled pages that are ready for implementation by designers and developers.

Each template provides a standardized page structure, ensuring consistency, maintainability, scalability, and accessibility throughout the website.

---

# Objectives

The Templates layer aims to:

- Standardize page composition.
- Encourage reuse of approved components.
- Reduce implementation inconsistencies.
- Improve development efficiency.
- Simplify design reviews.
- Maintain accessibility compliance.
- Support future website expansion.

---

# Relationship to Other Design System Layers

```
Foundations
        ↓
Components
        ↓
Patterns
        ↓
Templates
        ↓
Development
```

Templates should never redefine components or interaction patterns.

Instead, they assemble them into complete page experiences.

---

# Template Principles

Every template should:

- Begin with approved navigation.
- Follow a logical content hierarchy.
- Reuse existing components.
- Maintain consistent spacing.
- Support responsive layouts.
- Meet accessibility requirements.
- Include clear conversion opportunities.

# Template Governance

New templates should:

- Solve a recurring page requirement.
- Reuse approved components.
- Follow existing patterns.
- Be reviewed before adoption.
- Include accessibility validation.
- Document future revisions.

---

# Accessibility Requirements

Every template must:

- Use semantic HTML landmarks.
- Support keyboard navigation.
- Follow heading hierarchy.
- Maintain sufficient color contrast.
- Support screen readers.
- Meet WCAG 2.2 AA requirements.

Accessibility must be considered during template design rather than after implementation.

---

# Responsive Behaviour

Templates must support:

- Mobile
- Tablet
- Laptop
- Desktop
- Large Desktop

Layouts should adapt using the Responsive Patterns specification.

---

# Performance Guidelines

Templates should:

- Prioritize above-the-fold content.
- Optimize media.
- Minimize layout shifts.
- Lazy-load non-critical resources.
- Support Core Web Vitals.
