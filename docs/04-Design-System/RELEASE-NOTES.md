# Overview

This document summarizes major Design System releases.

Unlike the detailed `CHANGELOG.md`, which records individual modifications, Release Notes communicate high-level improvements, milestones, migration guidance, and significant updates for designers, developers, QA engineers, and project stakeholders.

---

# Release Strategy

The Design System follows Semantic Versioning.

```
MAJOR.MINOR.PATCH
```

Example:

```
1.0.0

↓

1.1.0

↓

1.2.0

↓

2.0.0
```
