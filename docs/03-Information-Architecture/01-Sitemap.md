**Owner:** Product Team

**Version:** 1.0

**Status:** Approved

**Last Updated:** 30 July 2026

---

# Purpose

This document defines the logical structure of the website.

The sitemap serves as the foundation for navigation, page hierarchy, content organization, SEO planning, and future feature expansion.

---

# Design Principles

The sitemap has been designed using the following principles:

- Simplicity
- Discoverability
- Minimal navigation depth
- Mobile-first navigation
- SEO-friendly hierarchy
- Scalability
- Accessibility

---
