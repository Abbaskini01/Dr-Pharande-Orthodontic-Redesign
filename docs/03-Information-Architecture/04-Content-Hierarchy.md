# Purpose

This document defines the priority and organization of information across the website.

Content hierarchy ensures that users encounter the most important information first, reducing cognitive load and improving task completion.

A consistent hierarchy supports usability, accessibility, SEO, and conversion goals.

---

# Content Hierarchy Principles

The content strategy follows these principles:

- Most important information first
- Progressive disclosure
- Minimal cognitive load
- Trust before conversion
- Education before promotion
- Clear visual hierarchy
- Consistent information patterns

# Content Presentation Rules

Every page should follow this order:

1. Primary Heading (H1)
2. Supporting Introduction
3. Primary Content
4. Supporting Sections
5. Trust Elements
6. Primary Call-to-Action
7. Secondary Information
8. Footer

---

# Content Governance

Every content block should answer at least one of the following questions:

- What is this?
- Why does it matter?
- Why should the visitor trust it?
- What should the visitor do next?

Content that does not contribute to these objectives should be reconsidered or removed.

---

# Accessibility Considerations

Content hierarchy shall:

- Use semantic heading levels (H1–H6).
- Present information in a logical reading order.
- Avoid relying solely on visual styling to indicate importance.
- Ensure important content remains accessible to assistive technologies.

---

# SEO Considerations

The hierarchy should support:

- One H1 per page
- Logical heading structure
- Keyword relevance
- Internal linking
- Readable content organization
